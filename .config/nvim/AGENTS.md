# nvim

Part of the public `~/.dotfiles` repo (`~/.config/nvim` is a symlink to it). See `~/.dotfiles/AGENTS.md`.

- Never add secrets, work or client-specific content.
- Verify with `mise run check` (EmmyLua types) and `mise run test`; format with stylua.
- Conventional Commits with scope `nvim` (`fix(nvim): …`). Don't commit or push unless asked.
